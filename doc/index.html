Installer en 4 étapes

Il te faut un M5Stick (ESP32‑S3) et l'IDE Arduino.

  1. Bibliothèques. Installe M5Unified, ESP Async WebServer et Async TCP (auteur ESP32Async) depuis le gestionnaire de bibliothèques.
  2. Téléverse. Carte ESP32S3 Dev Module, USB CDC On Boot activé, schéma de partition avec SPIFFS, puis téléverse M5_Arcade.ino (télécharger le fichier).
  3. Configure. Bouton B jusqu'à SETUP, connecte‑toi à M5-Setup, ouvre 192.168.4.1 (admin / 1234) : ajoute ton Wi‑Fi et ton dépôt GitHub.
  4. Joue. Télécharge un jeu par son nom (pong.html), passe en AP JEU et connecte un téléphone à M5-Arcade.

Crée ton jeu multijoueur

Le M5Stick relaie les messages : il te suffit d'ouvrir une WebSocket sur /ws. Il donne à chaque joueur sa place et la liste des présents.

Voir des exemples dans le dépôt des jeux →

const ws = new WebSocket("ws://" + location.host + "/ws");
ws.onmessage = e => {
  const m = e.data;
  if (m[0] === "I") me = +m.slice(1);        // ma place
  else if (m[0] === "C") mask = +m.slice(1); // joueurs présents
  else onMessage(m);                          // messages des autres
};
ws.send("coup 4");        // vers tous les autres
ws.send("@0|coup 4");     // vers la place 0 seulement
